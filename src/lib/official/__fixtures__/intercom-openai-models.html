November 24, 2026

Healthcare model configurations in the OpenAI API

Healthcare model configurations are now available in the OpenAI API. These configurations tailor models such as Astra and Sol for healthcare use cases. When web search is enabled, they can search a dedicated healthcare index to help developers build applications that find, compare, and summarize medical evidence with citations.

They’re available to API organizations through the Responses API. You don’t need a ChatGPT for Healthcare workspace to use them. These configurations do not replace professional medical judgment. For capabilities, availability, and requirements for handling protected health information, see: Healthcare model configurations in the OpenAI API.

November 17, 2026

GPT-6.2 Astra and GPT-6.2 Sol in the OpenAI API

We’re introducing GPT-6.2 Astra and GPT-6.2 Sol in the OpenAI API. Astra is our frontier model for applications that need advanced reasoning, coding, and the ability to handle complex professional work. Sol combines speed and lower cost with the ability to work through tasks that take several steps. Both improve on their predecessors’ results on demanding tasks while generating fewer output tokens.

Use gpt-6.2-astra or gpt-6.2-sol with the Responses or Chat Completions API. Both models accept text and images and return text, and review Standard API rates.

November 16, 2026

OpenAI CSAM image classifier

The OpenAI CSAM (Child Sexual Abuse Material) Image Classifier helps approved organizations review images for potential CSAM, including AI-generated material. Access is available through the OpenAI API at no cost and requires approval.

The classifier returns scores that can help trained reviewers prioritize review. It does not replace human judgment. Organizations remain responsible for reviewing results and deciding what action to take, including any reporting obligations.

Access requires an application, verification, program onboarding, and acceptance of the applicable terms. For application instructions, see: Requesting access to the OpenAI CSAM Image Classifier.

October 30, 2026

GPT-6 Rosalind Research

GPT-6 Rosalind Research brings GPT-6 reasoning capabilities to multistep life sciences research, with safeguards designed for biological work. It is rolling out to a limited set of approved Research customers in Work, Codex, and the API. It is not available in the Chat tab.

Access requires Rosalind Research approval for your organization and authorized users. Discovery approval does not grant Research access. Customers can continue to use GPT-5.5 Rosalind Research, and Rosalind Discovery remains on 5.5. On the API, use gpt-6-rosalind.

In Enterprise workspaces, the model starts in a two-week Admin Preview and is off by default. Admins can enable approved Research users and configure access for after the preview.

For access and setup, see: GPT-Rosalind for life sciences research. For pricing, see: API pricing, the credit-based rate card, or the Enterprise token-based rate card.
